# SmartLearn Hub 🎓

SmartLearn Hub is an open-source interactive learning application built using pure HTML5, CSS3, and modern vanilla JavaScript. It offers practice modules for core math skills alongside age-adapted reading comprehension.

---

## 🌟 Key Features

* **Times Tables Mastery**: Practice multiplication tables from **1 to 12** individually, or test your skills with a randomized mix.
* **Multi-Digit Addition**: Practice vertical column addition across **3-digit, 4-digit, 5-digit, and 6-digit** difficulties with real-time scoring and streaks.
* **Age-Adapted Reading Portal**:
  * **Year 1–6 (Ages 5–11)**: Short, simple narratives (~70 words).
  * **Year 7–12 (Ages 11–18)**: Sci-fi and adventure narratives (~100 words).
  * **Ages 16–35**: Intermediate essays on urban planning & society (~150 words).
  * **Ages 36+**: Comprehensive, long-form essays on psychology, philosophy, and history (~250+ words).

## 🚀 How to Publish on GitHub Pages

1. **Create a GitHub Repository**:
   * Go to [GitHub](https://github.com) and create a new public repository (e.g., `smartlearn-hub`).

2. **Upload Files**:
   * Upload `index.html`, `styles.css`, `script.js`, and `README.md` directly to the root of your repository main branch.

3. **Enable GitHub Pages**:
   * Go to your repository **Settings** → **Pages** (under Code and automation).
   * Under **Build and deployment** > **Source**, select **Deploy from a branch**.
   * Set Branch to `main` (or `master`) and folder to `/ (root)`.
   * Click **Save**.

4. **Access your App**:
   * Your site will be live at `https://<your-username>.github.io/<your-repo-name>/`.

---

## 💻 Local Setup
1. Clone or download this repository.
2. Open `index.html` directly in any browser. No web server or `npm` build step required!
